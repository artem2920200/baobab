# 🧱 Wall Bot — плотности стакана Binance Futures

Торговый бот, который в реальном времени анализирует стакан лимитных заявок
USDT-M фьючерсов Binance, находит аномально крупные уровни («плотности»),
ждёт подхода цены и входит **на отскок** от стены — с автоматическим стопом
за плотность и лестницей фиксации прибыли.

## Логика стратегии

1. **Фильтр монет** (каждые 5 минут):
   - объём торгов за 24ч **> $1 млн**;
   - **NATR(14) на 5m ≤ 1%** (спокойные монеты, без бешеной волатильности);
   - в работу берутся топ-50 по объёму среди прошедших фильтр.
2. **Стакан в реальном времени**: WebSocket diff-depth стримы + локальные
   стаканы по официальному протоколу синхронизации Binance.
3. **Поиск плотности**: уровень (или кластер соседних уровней) считается
   стеной, если его объём в $ **≥ 2× рыночного объёма сделок за последние
   15 минут** по этой монете. Дополнительно: абсолютный минимум $20K,
   концентрация (крупный уровень внутри кластера) и аномальность относительно
   соседних уровней (≥ 8× медианы).
4. **Подход цены**: когда цена подходит к стене на **0.10%** →
   уведомление (Telegram + веб + звук) и автоматический вход:
   - бид-стена снизу → **LONG** на отскок вверх;
   - аск-стена сверху → **SHORT** на отскок вниз.
5. **Стоп-лосс — за плотность**: за дальней границей стены + буфер 0.10%.
   Размер позиции считается от риска: **1% депозита** на расстояние до стопа.
6. **Фиксация прибыли (лестница)** — % движения цены от входа:
   | Движение | Действие |
   |---|---|
   | **+1%** | закрыть **50%** позиции, стоп → **безубыток** |
   | **+2%** | закрыть ещё **25%** от исходной позиции |
   | **+3%** | закрыть остаток (25%) |
7. **Защита от спуфинга**:
   - вход только если стена «живёт» ≥ 2 секунд;
   - если стену **сняли** до входа — вход отменяется;
   - если стену сняли **после входа** — позиция закрывается по рынку
     (отключается `exit_on_wall_pull: false`);
   - если стену **пробили** — срабатывает стоп за ней.

Все пороги настраиваются в `config.yaml`.

## Быстрый старт

```bash
cd wall-bot
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python run.py                    # конфиг config.yaml
# открой http://localhost:8000
```

Полезные флаги:

```bash
python run.py --mode paper       # симуляция на реальных данных
python run.py --demo             # синтетический рынок (отладка интерфейса)
python run.py --port 8080
```

## Режимы торговли

| Режим | Что делает | Ключи |
|---|---|---|
| `paper` | симуляция сделок по ценам стакана, комиссии и проскальзывание учитываются, PnL и equity сохраняются в `data/` | не нужны |
| `testnet` | реальные ордера на Binance Futures Testnet (рыночные данные — с mainnet) | ключи с testnet.binancefuture.com |
| `live` | **реальные деньги**: MARKET-вход, STOP_MARKET за стеной, TAKE_PROFIT_MARKET на +1/2/3%, перевод стопа в БУ после TP1 | ключи Binance Futures |

В `config.yaml` по умолчанию стоит `mode: live`. **Без API-ключей бот не
торгует** — он запускается как монитор: показывает плотности и шлёт
уведомления. Чтобы включить торговлю, впиши ключи:

```yaml
api:
  key: "..."
  secret: "..."
```

или через переменные окружения `BINANCE_API_KEY` / `BINANCE_API_SECRET`.

> ⚠️ **Настоятельно рекомендую**: прежде чем включать `live`, прогони бота
> в `paper` хотя бы несколько дней и посмотри статистику. Стены в стакане
> часто оказываются спуфингом — бот защищается от этого, но гарантий нет.
> Для live-ключа отключи вывод средств и включи торговлю только на фьючерсах.

### Как исполняются сделки в live

- вход: `MARKET` (изолированная маржа, плечо из конфига);
- сразу после входа: `STOP_MARKET` (reduceOnly) за стеной +
  `TAKE_PROFIT_MARKET` (reduceOnly) на уровнях +1%, +2%, +3%;
- исполнение читается из user data stream; после TP1 старый стоп
  отменяется и ставится новый на цене входа (безубыток);
- если защитные ордера не удалось выставить — **аварийное закрытие**
  позиции по рынку (голых позиций бот не оставляет);
- чужие позиции, открытые не ботом, он не трогает (предупредит при старте).

## Telegram-уведомления

1. Создай бота у [@BotFather](https://t.me/BotFather) → получи токен.
2. Напиши своему боту любое сообщение, затем узнай `chat_id`
   (например, через `https://api.telegram.org/bot<ТОКЕН>/getUpdates`).
3. Впиши в конфиг:

```yaml
telegram:
  enabled: true
  token: "123456:ABC..."
  chat_id: "123456789"
```

События в Telegram: подход цены, вход, каждый тейк, безубыток, стоп,
закрытие, снятие стены, ошибки. В веб-интерфейсе — все события + звук.

## Веб-интерфейс

- **Плотности** — все найденные стены: монета, сторона, цена, объём $,
  отношение к 15-мин объёму, дистанция цены, NATR, возраст, статус
  (ждёт / подходит / сигнал / снята / пробита). Фильтры и сортировка.
- **Позиции** — открытые сделки: вход, стоп (с бейджем БУ), прогресс
  лестницы +1% → +2% → +3%, PnL, кнопка ручного закрытия.
- **История** — закрытые сделки с PnL и причиной выхода.
- **События** — журнал + всплывающие уведомления + звуковые сигналы.
- Переключатели **Автоторговля** и **Звук** в шапке.

## Основные настройки (config.yaml)

| Параметр | Default | Смысл |
|---|---|---|
| `scan.min_volume_24h_usd` | 1000000 | дневной объём |
| `scan.natr_max_pct` | 1.0 | максимум NATR(14) 5m |
| `scan.max_symbols` | 50 | сколько монет держать в работе |
| `walls.ratio` | 2.0 | стена ≥ ×2 к объёму за 15м |
| `walls.min_wall_usd` | 20000 | минимальная стена, $ |
| `walls.max_distance_pct` | 2.0 | глубина поиска стен от цены |
| `signal.approach_pct` | 0.10 | дистанция срабатывания сигнала |
| `trading.risk_per_trade` | 0.01 | риск 1% депозита на сделку |
| `trading.max_leverage` | 5 | плечо |
| `trading.max_open_positions` | 3 | лимит одновременных позиций |
| `trading.cooldown_sec` | 900 | пауза по монете после закрытия |
| `trading.stop_buffer_pct` | 0.10 | буфер стопа за стеной |
| `trading.max_stop_pct` | 1.0 | дальше — сделку пропускаем |
| `trading.take_profit` | 1%/2%/3% | лестница фиксации |
| `trading.exit_on_wall_pull` | true | выход при снятии стены |

## Важно понимать

- **×2 к 15-минутному объёму — жёсткий фильтр.** На BTC/ETH такие стены
  почти не встречаются (нужны сотни миллионов $ в одном уровне). Основные
  срабатывания будут на альтах со спокойным NATR — это нормально и
  соответствует твоим критериям. Хочешь больше сигналов — снизь `walls.ratio`.
- Крупные лимитники часто **спуфинг**: их ставят, чтобы толкнуть цену, и
  убирают перед касанием. Бот фильтрует это (возраст стены, отмена входа,
  выход при снятии), но полностью риск не убирается.
- Бот не гарантирует прибыль. Это инструмент автоматизации твоей идеи;
  начинай с paper и малых сумм.
- Дашборд без авторизации — не выставляй порт в интернет без файрвола/VPN.
